VINAYAK SAINI PORTFOLIO — NETLIFY DEPLOYMENT

This is a static, single-page HTML website. No build command is required.

NETLIFY DROP DEPLOY:
1. Extract this ZIP file.
2. Open Netlify and go to https://app.netlify.com/drop
3. Drag the extracted folder named vinayak-portfolio-netlify onto the drop area.
4. Netlify should publish index.html from the folder root.

NETLIFY BUILD SETTINGS (if connecting a Git repository):
Build command: leave blank
Publish directory: .

The _redirects and netlify.toml files provide a fallback to index.html for client-side paths.
